# 电子书管理器 v3.1

基于 PyQt6 的跨平台电子书管理工具。

## 功能特性

### 多种视图模式
- 📋 **列表视图**：表格列表展示所有电子书，含封面缩略图和完整字段，支持列头排序
- 📚 **书架视图**：卡片式展示，只显示封面、标题和作者，悬停查看详情，点击打开详情窗口
- 🌳 **目录树视图**：根据文件目录自动分组显示树状结构，默认全展开，悬停显示封面和其他信息

### 分类管理功能
- 🏷️ **自定义分类**：支持两级分类配置（分类、子分类）
- ⚡ **快速配置**：支持粘贴纯文本格式快速导入分类配置，格式示例：
  ```
  推理
  推理/东野圭吾
  科幻
  科幻/大刘
  科幻/斯卡尔奇
  ```
- 🔗 **级联选择**：在详情页修改时，分类和子分类下拉框联动
- 📊 **全视图显示**：三个视图及详情/修改页均显示分类和子分类信息，未配置时显示"-"

### 核心功能
- 🔍 搜索功能：支持标题、副标题、作者、ISBN、分类、标签、分类、子分类等多字段模糊查询
- 🔄 排序功能：点击列头按该列升序/降序排序，支持按分类、子分类排序
- 📥 导入功能：支持拖拽、文件选择、文件夹选择，自动跳过已存在的文件
- 📖 格式支持：EPUB、PDF
- ✏️ 详情管理：查看和修改所有字段信息，支持删除书籍记录
- 🚀 快速打开：双击用系统默认应用打开电子书
- 🖼️ 封面显示：自动提取 EPUB 和 PDF 封面
- 🌐 豆瓣解析：从豆瓣获取书籍详细信息（使用 lxml + XPath 稳定解析）
  - 解析成功后自动进入编辑模式，由用户确认后保存
  - 解析失败仅提示用户，不自动保存
- ✅ 批量操作：支持全选/反选、批量解析豆瓣信息、批量删除、批量重命名
- 📝 批量重命名：自动将文件重命名为「标题 - 作者.扩展名」格式
- 📤 数据导出：支持将书籍列表导出为 CSV 格式，包含文件信息和豆瓣数据
  - `dir_root` - 分类（用户自定义）
  - `dir_sub` - 子分类（用户自定义）
  - `full_dir` - 完整分类路径，格式为「分类/子分类」
  - 导出规则：
    - 两个都没有：`,,`
    - 只有分类：`科幻,,科幻`
    - 两个都有：`科幻,斯卡尔奇,科幻/斯卡尔奇`

### 数据导出字段说明
| 字段 | 说明 |
|------|------|
| file_name | 文件名 |
| file_type | 文件类型（扩展名） |
| dir_root | 分类（用户自定义） |

| full_dir | 完整分类路径（分类/子分类） |

## 安装

```bash
pip install -r requirements.txt
```

## 使用说明

### 分类配置

1. 点击「设置」按钮，切换到「分类配置」标签页
2. **手动添加**：
   - 输入分类名称，点击「添加分类」添加一级分类
   - 选中分类后，输入子分类名称，点击「添加子分类」
   - 选中分类或子分类，点击「删除」移除
3. **快速配置**：
   - 点击「快速配置」按钮
   - 粘贴分类配置文本（每行一个，使用 `/` 分隔分类和子分类）
   - 点击「确定」导入配置
4. 配置完成后点击「保存」

### 批量操作

1. **全选/反选**：点击「全选」按钮选中所有书籍，点击「反选」按钮反转当前选中状态
2. **批量重命名**：选中需要重命名的书籍后，点击「批量重命名」按钮，系统会自动将文件重命名为「标题 - 作者.扩展名」格式
   - 文件不存在时自动跳过
   - 自动过滤文件名中的非法字符
   - 目标文件已存在时跳过避免覆盖
3. **导出CSV**：点击「导出CSV」按钮，可将所有书籍信息导出为 CSV 文件

### 豆瓣解析

1. 在详情页点击「从豆瓣获取信息」按钮
2. 解析成功后：
   - 自动填入获取的信息
   - 自动进入编辑模式
   - 提示用户确认信息后手动点击保存
3. 解析失败时：
   - 仅弹出提示框显示失败原因
   - 不会自动修改或保存任何信息

### 视图切换

1. **列表视图（默认）**：以表格形式展示所有书籍信息，支持多选、排序等操作
2. **书架视图**：以卡片形式展示书籍封面、标题和作者
   - 鼠标悬停在卡片上可查看详细信息（出版社、出版日期、ISBN、评分、分类、子分类等）
   - 点击卡片打开详情窗口
3. **目录树视图**：根据文件所在目录自动分组
   - 默认全部展开，可点击文件夹图标展开/折叠
   - 鼠标悬停在书籍项上可查看封面和详细信息
   - 双击书籍项打开详情窗口

**注意**：每次启动程序默认还原到列表视图。

## 运行

```bash
python main.py
```

## 配置豆瓣 Cookie

1. 在浏览器中登录 [豆瓣](https://www.douban.com)
2. 按 F12 打开开发者工具，切换到 Network（网络）标签
3. 刷新页面，点击任意请求
4. 在请求头中复制完整的 Cookie 值
5. 在程序中点击 `设置` → `豆瓣配置`，粘贴 Cookie 并保存

## 注意事项

- 删除书籍记录只会删除数据库中的信息，不会删除源文件
- 封面图片会自动保存到 `covers` 目录
- 数据库文件 `ebook_manager.db` 会在程序首次运行时自动创建
- 分类配置文件保存在 `categories.json`
- 豆瓣解析需要配置有效的 Cookie，且有访问频率限制
- 建议定期备份数据库文件、封面目录和分类配置文件
