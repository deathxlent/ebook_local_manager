# 电子书管理器

基于 PyQt6 的跨平台电子书管理工具，支持 EPUB、PDF 格式，集成豆瓣书籍信息解析。

## 快速开始

### 环境要求

- Python 3.10+
- Windows / Linux / macOS

### 安装依赖

```bash
pip install -r requirements.txt
```

依赖列表：
- PyQt6>=6.4.0
- ebooklib>=0.18
- Pillow>=10.0.0
- beautifulsoup4>=4.12.0
- lxml>=4.9.0
- pypdf>=4.0.0
- requests>=2.28.0

### 启动应用

```bash
python main.py
```

## 功能详解

### 1. 导入电子书

**入口**：菜单栏「导入电子书」

支持三种导入方式：
- **选择文件** — 弹出文件选择对话框，可多选 `.epub` / `.pdf` 文件
- **选择文件夹** — 自动扫描文件夹及其子目录中的所有支持的电子书
- **拖拽导入** — 将文件或文件夹直接拖拽到导入窗口

导入流程：
1. 选择/拖入文件后，窗口显示待导入文件数量
2. 自动跳过已存在于数据库中的文件和重复文件
3. 点击「开始导入」执行导入
4. 进度条实时显示进度，日志区显示每本书的导入结果
5. 导入完成后显示成功、跳过重复、跳过其他的数量统计

导入时自动提取：
- 文件元数据（标题、作者、出版社等）
- 封面图片（保存到 `covers/` 目录）
- 文件大小、格式、路径

### 2. 搜索与筛选

**搜索框**：输入关键词后实时搜索，支持以下字段模糊匹配：
- 标题、副标题、作者、ISBN、标签
- 出版社、出版日期、扩展名、文件路径
- 分类、子分类

**二次筛选**：搜索后会出现第二个输入框，可在搜索结果中进行二次筛选。

### 3. 排序

在列表视图中，点击列头可按该列排序：
- 首次点击：升序
- 再次点击同一列：降序
- 支持排序的列：标题、副标题、作者、出版社、出版日期、文件大小、路径、格式、ISBN、评分、分类、子分类

### 4. 三种视图

#### � 列表视图（默认）

表格形式展示所有书籍，每行显示：
- 复选框（用于批量选择）
- 封面缩略图 / 解析状态图标（⏳ 解析中 / ✓ 已解析 / ✗ 解析失败）
- 标题、副标题、作者、出版社、出版日期、文件大小、物理位置、扩展名、ISBN、评分、标签、分类、子分类
- 操作按钮：「📖 打开」（系统默认应用打开）、「✏️」（编辑详情）

双击任意行（除复选框列）可打开详情窗口。

#### 📚 书架视图

卡片式布局，每张卡片显示封面、标题、作者。

交互方式：
- **悬停** — 弹出详细信息提示（出版社、ISBN、评分、分类等）
- **单击** — 选中/取消选中该书
- **双击** — 打开详情窗口
- 卡片自适应窗口宽度排列

#### 🌳 目录树视图

根据文件所在目录自动分组显示树状结构。

交互方式：
- **悬停** — 弹出封面和详细信息提示
- **单击** — 切换选中状态（复选框联动）
- **双击** — 打开详情窗口
- 文件夹节点显示包含的书籍数量

> 三种视图共享选中状态，切换视图时保持选中。

### 5. 书籍详情窗口

**入口**：列表视图双击行 / 书架视图双击卡片 / 目录树视图双击项 / 列表操作栏「✏️」按钮

详情窗口展示和编辑一本书的完整信息：

#### 显示字段

| 区域 | 字段 |
|------|------|
| 左侧 | 封面图片、「更换封面」按钮、「还原封面」按钮 |
| 右侧 | 标题、副标题、作者、出版社、出版日期、ISBN、分类（级联下拉）、子分类（级联下拉）、标签、评分、豆瓣链接、豆瓣ID、页数 |
| 文件信息 | 格式、大小、路径（只读） |
| 备注区 | 简介、个人备注 |

#### 底部操作按钮

| 按钮 | 功能 |
|------|------|
| ⬅️ 上一本 / 下一本 ➡️ | 在书籍列表中翻页浏览 |
| � 从豆瓣解析 | 根据书名和作者从豆瓣获取信息 |
| 📖 打开书籍 | 用系统默认应用打开电子书文件 |
| 🖼️ 更新封面到文件 | 将当前封面写入原始电子书文件 |
| 📝 更新元数据到文件 | 将当前元数据写入原始电子书文件 |
| 🔤 重命名 | 将文件重命名为「标题 - 作者.扩展名」 |
| ✏️ 修改 / 💾 保存 | 切换编辑/保存模式 |
| 🗑️ 删除 | 删除该书记录 |

#### 编辑模式

点击「✏️ 修改」进入编辑模式：
- 所有字段变为可编辑
- 分类下拉框可编辑（可手动输入新分类）
- 子分类下拉框联动分类变化
- 按钮变为「💾 保存」

点击「💾 保存」保存修改并退出编辑模式。

#### 豆瓣解析流程

1. 点击「🔍 从豆瓣解析」
2. 若未配置 Cookie，自动弹出豆瓣配置窗口
3. 解析中按钮显示「⏳ 解析中...」
4. **解析成功**：
   - 自动填入所有豆瓣信息（标题、作者、ISBN、评分、封面等）
   - 自动进入编辑模式
   - 焦点自动跳转到分类下拉框并展开
   - 用户确认信息后手动保存
5. **解析失败**：弹出提示框显示失败原因，不修改任何数据

#### 分类级联选择

- 选择分类后，子分类下拉框自动更新为该分类下的子分类列表
- 若子分类有内容，自动展开子分类下拉框
- 下拉框显示项数根据实际数量自适应（最多显示 15 项）

#### 封面操作

- **更换封面** — 从本地选择图片替换当前封面
- **还原封面** — 从原始电子书文件重新提取封面
- **更新封面到文件** — 将当前封面写入 EPUB/PDF 文件（操作前需确认，会修改原文件）

#### 元数据写入

- **更新元数据到文件** — 将当前编辑的元数据写入 EPUB/PDF 文件（操作前需确认，会修改原文件）
- 仅支持 EPUB 和 PDF 格式

### 6. 批量操作

#### 全选/反选

- **全选** — 选中所有书籍；若已全选则取消全选
- **反选** — 反转每本书的选中状态

#### 批量删除

1. 选中要删除的书籍
2. 点击「🗑️ 批量删除」
3. 确认删除（仅删除数据库记录，不删除源文件和封面）
4. 自动删除关联的封面文件

#### 批量重命名

1. 选中要重命名的书籍
2. 点击「📝 批量重命名」
3. 确认操作
4. 文件自动重命名为「标题 - 作者.扩展名」格式

规则：
- 标题为空或文件不存在时跳过
- 目标文件已存在时跳过（避免覆盖）
- 自动过滤文件名中的非法字符（`<>:"/\|?*` 替换为 `_`）

#### 导出封面

1. 选中要导出封面的书籍
2. 点击「🖼️ 导出封面」
3. 选择导出目录
4. 封面以「标题 - 作者.jpg」格式保存

规则：
- 无封面或封面文件不存在时跳过
- 同名文件自动添加序号后缀

### 7. 导出 CSV

**入口**：菜单栏「导出CSV」或工具栏「📤 导出CSV」

将当前书籍列表导出为 CSV 文件（Tab 分隔，UTF-8 编码，兼容 Excel）。

导出字段：

| 字段 | 说明 |
|------|------|
| file_name | 文件名 |
| file_type | 文件类型（扩展名） |
| dir_root | 分类 |
| dir_sub | 子分类 |
| full_dir | 完整分类路径（分类/子分类） |
| douban_rank | 豆瓣评分 |
| summary | 内容简介 |
| douban_title | 豆瓣标题 |
| douban_author | 豆瓣作者 |
| douban_isbn | ISBN |
| douban_url | 豆瓣链接 |
| douban_tags | 标签 |

`full_dir` 生成规则：
- 无分类：空
- 仅有分类：`科幻`
- 有分类和子分类：`科幻/大刘`

### 8. 豆瓣配置

**入口**：菜单栏「豆瓣配置」

配置豆瓣 Cookie 以使用豆瓣信息解析功能。

获取 Cookie 步骤：
1. 在浏览器中登录 [豆瓣](https://www.douban.com)
2. 按 F12 打开开发者工具
3. 切换到 Network（网络）标签
4. 刷新页面，点击任意请求
5. 在请求头中复制完整的 Cookie 值
6. 粘贴到配置窗口并保存

注意事项：
- Cookie 为空时保存会二次确认
- Cookie 过期后需要重新配置
- 解析请求间隔约 5 秒，避免被豆瓣限制

### 9. 分类配置

**入口**：菜单栏「分类配置」

管理书籍的两级分类体系（分类/子分类）。

#### 手动管理（左侧）

- 「+ 分类」 — 添加一级分类
- 「+ 子分类」 — 选中一级分类后添加子分类
- 「- 删除」 — 删除选中的分类或子分类

#### 快速配置（右侧）

支持粘贴纯文本批量导入分类，格式：

```
推理
推理/东野圭吾
科幻
科幻/大刘
科幻/斯卡尔奇
```

每行一个条目：
- 纯文本 → 一级分类
- 含 `/` → 分类/子分类

操作：
- 「📤 导出当前」 — 将当前分类导出为文本格式
- 「📥 导入配置」 — 导入文本配置（覆盖当前所有分类）

### 10. 一键清理

**入口**：菜单栏「一键清理」或工具栏「🧹 一键清理」

扫描并清理：
1. **未关联的封面文件** — `covers/` 目录中不被任何书籍记录引用的封面图片
2. **物理文件不存在的书籍记录** — 书籍文件已被移动或删除，但数据库记录仍在

操作前会展示待清理内容的详细信息，确认后执行。

## 数据存储

程序运行时会自动创建以下文件：

| 文件/目录 | 说明 |
|-----------|------|
| `ebook_manager.db` | SQLite 数据库，存储书籍信息 |
| `config.json` | 配置文件，存储豆瓣 Cookie 和分类配置 |
| `covers/` | 封面图片目录 |

### 书籍字段

| 字段 | 说明 |
|------|------|
| title | 标题 |
| subtitle | 副标题 |
| authors | 作者（逗号分隔） |
| publisher | 出版社 |
| pubdate | 出版日期 |
| isbn | ISBN |
| dir_root | 分类（用户自定义） |
| dir_sub | 子分类（用户自定义） |
| tags | 标签（逗号分隔） |
| series | 丛书 |
| rating | 评分（0-10） |
| douban_url | 豆瓣链接 |
| douban_id | 豆瓣 ID |
| summary | 内容简介 |
| notes | 个人备注 |
| cover_path | 封面本地路径 |
| cover_url | 封面网络地址 |
| file_size | 文件大小 |
| physical_path | 文件路径（唯一） |
| extension | 扩展名 |
| page_count | 页数 |
| parse_status | 解析状态（pending/parsing/success/failed） |
| last_parsed_at | 最后解析时间 |

---

## 注意事项

- 删除书籍记录只会删除数据库中的信息，**不会删除源文件**
- 更新封面/元数据到文件会**修改原始电子书文件**，建议先备份
- 豆瓣解析需要配置有效的 Cookie，且有访问频率限制（间隔约 5 秒）
- 每次启动程序默认使用列表视图
- 建议定期备份 `ebook_manager.db`、`covers/` 目录和 `config.json`
